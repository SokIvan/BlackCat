# 🐾 BlackCat

**Special Security System for your PC** — система компьютерного зрения, которая через веб-камеру отслеживает появление посторонних лиц за вашим компьютером и отправляет уведомление в Telegram с фотографией незнакомца и скриншотом экрана.

## 🔍 О проекте

BlackCat — это pet-проект на Python, объединяющий компьютерное зрение, асинхронный бэкенд и Telegram-бота для мониторинга безопасности рабочего места.

**Как это работает:**
1. Клиентский модуль (`cat`) захватывает видеопоток с веб-камеры через OpenCV.
2. Каждый кадр анализируется библиотекой `face_recognition` (на базе dlib) — обнаруженные лица сравниваются с базой известных лиц в Supabase.
3. Если в кадре появляется лицо, отсутствующее в базе, клиент делает скриншот экрана (`mss`).
4. Фото незнакомца и скриншот отправляются на сервер.
5. Сервер (`server`) через Telegram-бота (Aiogram) присылает вам уведомление с обоими изображениями.
6. Управление системой (добавление/удаление лиц, включение/выключение мониторинга) — через команды Telegram-бота.

## 🏗 Архитектура

Проект имеет клиент-серверную архитектуру:

```
BlackCat/
├── cat/            # Клиентский модуль (работает на охраняемом ПК)
│   ├── main.py     # Захват видео, распознавание лиц, отправка на сервер
│   └── ...
└── server/         # Серверный модуль (бэкенд + Telegram-бот)
    ├── main.py     # FastAPI + Aiogram, REST API, обработка уведомлений
    └── ...
```

- **cat** — работает на компьютере, который нужно охранять. Захватывает видео с веб-камеры, распознаёт лица, делает скриншоты и отправляет их на сервер.
- **server** — принимает данные от клиента, хранит базу лиц в Supabase, управляет Telegram-ботом для отправки уведомлений пользователю.

## 🛠 Технологии

| Компонент | Технологии |

## 📦 Установка

### Требования
- Python 3.8+
- Веб-камера
- Установленный [dlib](https://github.com/davisking/dlib) (требует CMake и компилятор C++)
- Аккаунт [Supabase](https://supabase.com/) для базы данных
- Telegram-бот (создать через [@BotFather](https://t.me/BotFather))

### Шаги

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/SokIvan/BlackCat.git
   cd BlackCat
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # или: venv\Scripts\activate  # Windows
   pip install -r cat/requirements.txt
   pip install -r server/requirements.txt
   ```

3. Настройте переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен Telegram-бота от BotFather
   - `SUPABASE_URL` — URL вашего проекта Supabase
   - `SUPABASE_KEY` — API-ключ Supabase
   - `TELEGRAM_CHAT_ID` — ваш chat ID для получения уведомлений

4. Запустите сервер:
   ```bash
   cd server
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```

5. В отдельном терминале запустите клиент:
   ```bash
   cd cat
   python main.py
   ```

## 🤖 Команды Telegram-бота

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация пользователя |
| `/add_face` | Добавить новое лицо в базу (отправьте фото) |
| `/remove_face` | Удалить лицо из базы |
| `/list_faces` | Показать список известных лиц |
| `/status` | Текущий статус мониторинга |
| `/enable` | Включить мониторинг |
| `/disable` | Выключить мониторинг |

## 📋 Сценарии применения

- **Домашний компьютер** — узнать, кто садился за ПК в ваше отсутствие
- **Рабочее место в офисе** — контроль доступа к рабочей станции
- **Удалённый сервер с подключённой камерой** — мониторинг физического доступа
- **Учебная/научная лаборатория** — отслеживание доступа к оборудованию

## 📷 Как это выглядит

При срабатывании системы в Telegram приходит сообщение с:
- Фотографией незнакомца (кадр с веб-камеры)
- Скриншотом экрана компьютера в момент обнаружения

## ⚠️ Ограничения

- Точность распознавания зависит от качества камеры и освещения
- Библиотека `face_recognition` работает лучше на Linux/macOS (на Windows требуется установка dlib через CMake)
- Система не является заменой профессиональным решениям безопасности
